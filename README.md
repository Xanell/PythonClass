# 🚗 Автомойка самообслуживания (учебный проект)

## Описание проекта

Данный проект реализует упрощённую модель вендингового автомата на примере автомойки самообслуживания. Разработан в рамках изучения принципов объектно-ориентированного программирования (ООП) на языке Python.

Система моделирует работу бокса ручной автомойки (`StandardWashBox`), который поддерживает различные режимы мойки, способы оплаты (наличные или мобильное приложение), контроль запасов химии (пены и воска) и учёт выручки.

Проект демонстрирует:
- наследование (базовый класс `AbstractCarWash`);
- полиморфизм (возможность расширения другими типами моек);
- использование перечислений для статусов и режимов;
- обработку исключений и валидацию входных данных.

| `AbstractCarWash` | Базовый класс автомойки. Содержит общую логику: статус бокса, кассу, выручку, метод проведения оплаты. |

## Функциональность

### 1. Базовые операции

- **Проверка статуса бокса** – `get_status_report()` возвращает номер бокса, текущий статус, сумму наличных в кассе и общую выручку.
- **Перевод в режим обслуживания** – `set_maintenance_status()` / `finish_maintenance_status()`.
- **Проведение оплаты** – `process_payment(amount, payment_type, user)`:
  - при оплате наличными увеличивает `cash_box`;
  - при оплате через приложение списывает средства с баланса пользователя;
  - всегда увеличивает `total_revenue`.

### 2. Управление ресурсами (для `StandardWashBox`)

- `restock_foam(foam_liters)` – пополнение бака пены.
- `restock_wax(wax_liters)` – пополнение бака воска.
- При попытке залить больше максимума выводится сообщение об аварийном сливе излишков.

### 3. Запуск мойки

Универсальный метод `start_wash_session(mode, payment_type, user, duration_seconds, cash_amount)`:

- **Режим оплаты `APP`:**
  - Требуется указать пользователя и длительность (`duration_seconds > 0`).
  - Предварительно проверяется достаточность баланса: стоимость = длительность × тариф.
  - Мойка продолжается ровно указанное время, после чего списывается полная стоимость с баланса пользователя.

- **Режим оплаты `CASH`:**
  - Пользователь вносит наличную сумму `cash_amount`.
  - Мойка продолжается, пока внесённой суммы хватает на оплату каждой следующей секунды.
  - По окончании фиксируется фактическое время и стоимость, которые проводятся в кассу.

- **Остановка при нехватке ресурсов:**
  - Если во время работы заканчивается пена или воск, бокс переводится в состояние `MAINTENANCE`, а сессия завершается.
  - Оплата списывается только за фактически оказанное время.
