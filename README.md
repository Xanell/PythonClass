# PythonClass
# 📑 Бэкэнд-система управления сетью умных автомоек

Централизованная система контроля (Web API бэкэнд) для управления сетью автоматизированных и ручных моечных комплексов. Проект реализован на языке Python с применением передовых принципов объектно-ориентированного программирования (ООП), наследования и строгой обработки исключений (`raise`).

---

## 🌐 Глобальная архитектура системы

Бизнес-логика бэкэнда строго разделена на две независимые зоны ответственности (Separation of Concerns):
1. **Финансовое ядро пользователя (`User`):** Выступает владельцем виртуального кошелька, отвечает за личный кабинет клиента и пополнение счёта. Существует изолированно от железа автомоек.
2. **Ядро оборудования (`CarWash`):** Управляет физическими компонентами (датчиками баков, помповыми системами, купюроприемниками) и фиксирует чистую выручку на сервере.

---

## 📁 Структура модулей и классов проекта

### 1️⃣ Модуль перечислений (`Enums.py`)
Обеспечивает строгую типизацию данных в Web API и полностью исключает опечатки при передаче запросов с фронтенда:
*   `BoxStatus (Enum)`: Текущие состояния оборудования (`FREE` — свободен, `BUSY` — занят, `MAINTANCE` — на обслуживании/ремонте).
*   `BoxWashMode (Enum)`: Физические режимы пистолета ручной мойки (`WATER` — вода, `FOAM` — пена, `WAX` — воск).
*   `PaymentType (Enum)`: Поддерживаемые каналы оплаты (`APP` — списание с баланса приложения, `CASH` — внесение наличных в купюроприемник автомата).

### 2️⃣ Профиль клиента (`User_Class.py`)
Класс, инкапсулирующий финансовые средства и данные пользователя.
*   **Свойства (`__init__`):** `user_id: int`, `name: str`, `balance: float` (изначально `0.0`).
*   **Методы:**
    *   `deposit_money(amount: float) -> dict`: Пополнение кошелька. Защищен затвором `if amount <= 0: raise ValueError`. Возвращает API-структуру с новым балансом.
    *   `get_profile_report() -> dict`: Возвращает текущий отчет профиля для конвертации в JSON.

### 3️⃣ Базовый родительский класс (`AbstractCarWash.py`)
Единый финансовый и административный шаблон для любого типа моечного поста в сети. Напрямую объектом на сервере не создается.
*   **Свойства (`__init__`):** Принимает обязательные параметры `id`, `adress`, `box_number`. Самостоятельно инициализирует: статус `self.box_status = BoxStatus.FREE`, железный сейф для купюр `self.cash_box = 0.0` и общий счетчик чистой прибыли `self.total_revenue = 0.0`.
*   **Методы:**
    *   `process_payment(amount: float, payment_type: PaymentType, user: User) -> bool`: Универсальный пакетный затвор списания денег. Если выбран `CASH`, деньги мгновенно прибавляются в сейф `self.cash_box`. Если выбран `APP`, метод проверяет кошелек переданного объекта пользователя (`if user.balance < amount: raise ValueError`) и списывает всю сумму за раз. В конце увеличивает общую выручку `self.total_revenue += amount`.
    *   `get_status_report()`, `set_maintance_status()`, `finish_maintance_status()`: Методы диспетчеризации, мониторинга сейфа и аварийного перевода бокса в ремонт.

### 4️⃣ Дочерний класс ручного поста (`StandartWashBox.py`)
Пост самообслуживания, где клиент моет машину пистолетом. Тарификация и контроль баков осуществляются **посекундно в реальном времени**.
*   **Свойства (`__init__`):** Вызывает `super().__init__(id, adress, box_number)`. Инкапсулирует лимиты баков (`MAX_FOAM = 50.0`, `MAX_WAX = 10.0`), текущие остатки химии, расходы ресурсов за 1 секунду работы и посекундные тарифы (Вода — 0.15₽/сек, Пена — 0.40₽/сек, Воск — 0.30₽/сек).
*   **Методы работы с клиентом:**
    *   `start_wash_session_app_pay(mode, user, duration_seconds)`: Работает по таймеру приложения. Запускает бесконечный цикл `while True`. Каждую секунду списывает тариф из виртуальной копии баланса и вычитает химию из бака. Если сессия доходит до лимита времени, срабатывает `break`. Если в процессе кошелек или бак пустеют — вылетает `raise ValueError`, цикл прерывается, а бэкэнд считает фактически намытые секунды и **один раз в блоке `except`** списывает точную сумму через родительский `process_payment`.
    *   `start_wash_session_cash_pay(mode, cash_amount)`: Метод для бумажных купюр. Не принимает объект `user` и таймер времени. Принимаемая сумма сразу плюсуется в сейф бокса `self.cash_box += cash_amount` и выводится на экран сессии. Бесконечный цикл `while True` крутится «до упора» — пока внесенные деньги полностью не обнулятся посекундным списанием тарифа. В конце сессии фиксирует прибыль в родителе.
    *   `restock_foam()`, `restock_wax()`: Методы дозаправки баков техником (излишки свыше `MAX` автоматически срезаются).

### 5️⃣ Дочерний класс робота-портала (`RobotWashBox.py`)
Полностью автоматическая мойка-робот. **Не имеет секундных циклов, таймеров и посекундного списания**. Списание ресурсов и денег происходит фиксированными пакетами за одно нажатие кнопки.
*   **Свойства (`__init__`):** Вызывает `super().__init__(id, adress, box_number)`. Хранит уникальные огромные лимиты баков: чистая вода (`MAX_WATER = 500.0`л), робот-шампунь (`MAX_SHAMPOO = 20.0`л), осмос-воск для сушки кузова (`MAX_OSMOS_WAX = 5.0`л). По умолчанию баки создаются полными.
*   **Методы пакетных программ (Тарифы):**
    1.  `buy_package_express(payment_type, user)`: Цена `400.0` руб. Списывает пакетом 50л воды и 0.5л шампуня.
    2.  `buy_package_standard(payment_type, user)`: Цена `600.0` руб. Списывает пакетом 100л воды и 1.0л шампуня.
    3.  `buy_package_premium(payment_type, user)`: Цена `900.0` руб. Списывает пакетом 150л воды, 1.5л шампуня и 0.2л воска для сушки кузова.
    *   *Бизнес-логика программ:* Метод проверяет статус `FREE` и остатки всех баков робота. При нехватке хотя бы одного литра химии/воды — робот переводится в статус ремонта `MAINTANCE` и выбрасывает `raise ValueError`. Если ресурсов хватает — одной командой вызывается родительский `self.process_payment`, списываются ресурсы из баков, а метод возвращает успешный словарь-чек.
    *   `restock_robot_resources(water, shampoo, wax)`: Сервисный метод массовой заправки робота инженером.
